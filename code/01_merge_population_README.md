# 01_merge_population.py — 인구 데이터 병합 가이드

이 문서는 `01_merge_population.py`가 **무엇을, 왜** 하는지 설명합니다. 코드를 다시 열었을 때 "내가 왜 이렇게 짰더라?"를 바로 떠올릴 수 있게 하는 게 목적입니다.

## 목표

행정안전부(jumin.mois.go.kr)에서 시도별로 나눠 받은 인구 CSV 16개를,
**시군구 × 월(2026.01~06) × 연령대(6구간)** 하나의 테이블로 합치는 것.

이게 필요한 이유: 공모전 기획서의 1단계 "기준선 구축"에서
`기대소비액 E_r = Σ (지역 r의 연령대별 인구) × (전국 1인당 소비 프로파일)`
을 계산하려면, BC카드 소비데이터의 `AGE_CD` 구간과 **정확히 같은 모양**의 인구 데이터가 있어야 합니다.

## 원본 데이터의 특징

- 파일 1개 = 시도 1개 (예: `202601_202606_연령별인구현황_월간 (8).csv` = 경기도)
- 인코딩은 **EUC-KR** (UTF-8 아님 — 정부 통계 사이트 공통)
- 한 행 = 지역 하나. 단, **시도 합계 행**(`"경기도  (4100000000)"`)과
  **시군구 행**(`"경기도 수원시 (...)"`)이 섞여 있음 → 구분 안 하면 이중 집계 위험
- 컬럼은 `2026년0N월_{계|남|여}_{연령대}` 형태로 **6개월 × 3(성별) × 13(연령대)개 컬럼이 옆으로 펼쳐진(wide) 구조**
- BC카드 데이터의 AGE_CD는 6구간(20대이하/20대/30대/40대/50대/60대이상)인데,
  인구 데이터는 10세 단위 11구간(0~9세, 10~19세, ..., 100세 이상)이라 **일부는 합쳐줘야** 함
  - 20대이하 = 0~9세 + 10~19세
  - 60대이상 = 60~69세 + 70~79세 + 80~89세 + 90~99세 + 100세 이상

## 진행 단계

### Step 1. 파일 목록 확보
`glob.glob(".../population/*.csv")`로 16개 파일 경로를 리스트로 확보.

### Step 2~3. 인코딩 확인 및 읽기
기본 `pd.read_csv()`는 UTF-8을 기대해서 `UnicodeDecodeError` 발생 →
`encoding="euc-kr"` 지정해서 해결.

### Step 4. 지역명 / 지역코드 분리, 시도·시군구 구분
- 정규식 `^(.*?)\s*\((\d+)\)$` 으로 `"광주광역시  (2900000000)"` → `("광주광역시", "2900000000")` 분리
- 지역명에 공백이 있으면(`"광주광역시 동구"`) 시군구, 없으면(`"광주광역시"`) 시도 합계로 분류
  - ⚠️ 예외: 세종특별자치시처럼 하위 구/군이 없는 지역은 이름이 한 단어라 '시도'로 잘못 분류될 수 있음.
    나중에 BC카드 지역명과 매칭할 때 별도 처리 필요.

### Step 5. 16개 파일 합치기
- 16개 파일을 각각 `pd.read_csv(f, encoding="euc-kr")`로 읽어 리스트에 모음
- `pd.concat(frames, ignore_index=True)`로 세로로 이어붙임 (컬럼 구조가 16개 파일 모두 동일해서 가능)
- `drop_duplicates(subset=['행정구역'])`으로 혹시 모를 중복 지역행 제거 (안전장치)
- ⚠️ 합치기 전 총 행 수와 합친 후 행 수를 반드시 비교 — 다르면 왜 다른지 확인 필요

### Step 5-1. (실전에서 발생) 인코딩 예외 디버깅
16개 중 1개 파일에서 `euc-kr`로도 못 읽는 `UnicodeDecodeError`(byte 0x96) 발생.
- `for` 루프 안에 `try/except`를 넣어 **어떤 파일이 문제인지 먼저 특정**하는 방식으로 대응
  (정부 통계 사이트에서 나눠 받은 파일 중 일부가 CP949 등 다른 인코딩으로 저장되는 경우가 실무에서 종종 있음)
- 문제 파일만 따로 `encoding="cp949"`로 재시도 → 그래도 안 되면 `errors="replace"`까지 고려
- 원칙: 에러가 나면 전체를 다 갈아엎지 말고, **실패 지점만 좁혀서(isolate)** 원인을 찾는다

### Step 6 (예정). wide → long 변환 + 연령대 6구간으로 합치기
월(1~6)을 반복하면서 각 월의 `계_0~9세 + 계_10~19세` 등을 더해
`STRD_YYMM, 행정구역명, 행정구역코드, 구분수준, 20대이하_인구, 20대_인구, ...` 형태의
**긴(long) 테이블**로 재구성. 이 형태가 이후 BC카드 데이터와 조인하기 훨씬 쉬움.

### Step 7 (예정). 검증
- 시도별 인구 합계가 매월 정상 범위(전국 약 5,148만명)인지 확인
- 지역 수가 기대한 개수(약 267개 시군구)와 맞는지 확인

## 다음에 이 데이터로 할 일

1. BC카드 소비데이터(`ABP_CONTEST_DATA.csv`)의 시군구명과 이 파일의 `행정구역명`을 매칭
2. 전국 1인당 소비 프로파일 c(a,g) = 전국 총 이용금액(a,g) ÷ 전국 인구(a,g) 계산
3. 지역별 기대소비액 E_r = Σ pop(r,a,g) × c(a,g) 산출
