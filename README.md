# BC카드 시장 침투도 기반 공략 우선순위 발굴

**제1회 AI금융빅데이터플랫폼 소비데이터 공모전** · 팀 유비온
팀장 이성진 · 팀원 염신호 · 이규상

전국 227개 시군구 × 8개 업종의 **1,813개 시장** 전부에서 "이 정도 점포 수와 인구라면
나와야 할 BC 결제액"을 회귀로 추정하고, 실제와의 차이로 공략 우선순위를 매긴 분석입니다.

---

## 핵심 지표

| 지표 | 산식 |
|---|---|
| 모델예측 | 업종별 회귀 적합값 `exp(β₀ + β₁·log 점포수 + β₂·log 성인인구)` |
| **침투지수** | 실제 BC 소비 ÷ 모델예측 × 100 |
| 격차금액 | 모델예측 − 실제 소비 |
| 시장 백분위 | 모델예측의 업종 내 백분위 |
| **σ (표준화 이탈지표)** | `log(침투지수÷100)` ÷ 업종별 5-fold CV 예측오차 |
| 건수지수 | `log(건수) ~ log(점포수)+log(인구)` 예측 대비 실제 × 100 |

모델은 **업종별로 따로 적합**합니다 (8개). 8개를 한 식으로 묶으면 R²가 0.891에서
0.768로 떨어집니다 — 업종마다 점포 규모와 객단가가 다르기 때문입니다.

σ는 가설검정 통계량이 아니라 **순위 지표**입니다. 검증은 유의성 검정이 아니라
재현성(반기 재산출 σ 상관 0.946)과 홀드아웃 3종으로 합니다.

## 후보 선정 — 4단 필터

```
1,813개 시장
  → 침투지수 < 100            (예상에 못 미치는 시장)
  → 시장 백분위 > 50          (고쳐서 남는 게 있는 규모)
  → σ ≤ −1.5                  (예측오차 대비 하방 이탈)
  → 격차금액 20억 이상        (실행 가치)
= 12개 조합 · 10개 시군구
```

가중합으로 점수를 매긴 것이 아니라 **네 조건을 모두 통과해야 남는 방식**이라
항목 간 가중치 논쟁이 생기지 않습니다.

이어서 **업종 / 카테고리 / 지역 전체**의 3층 지수를 비교해 12개를
기회 유형 3가지(지역 전체 기회 · 업종 간 이동 · 채널 이동)로 나눕니다.

## 재현성

교차검증 폴드를 난수가 아니라 **순차 분할**(`idx[i::5]`)로 고정합니다.
난수로 나누면 업종별 CV 오차가 1%가량 흔들려 σ가 −1.5 경계에 있는 조합의
채택 여부가 실행할 때마다 바뀝니다.

## 구성

| 경로 | 내용 |
|---|---|
| `code/분석코드.ipynb` | **★ 메인 — 분석 본류 전체.** 데이터 결합 → 회귀 → σ → 후보 선정 → 유형 → 검증 |
| `code/03_심층분석.ipynb` | 연령 분해 · 대형마트 통제 · 대조군 선정 · 최소 탐지 기준 |
| `code/부록_지표검증.ipynb` | 잔차 진단 4종 · 다중공선성 · 점포 수 수집(공공데이터포털 API) |
| `code/population.ipynb` | 주민등록인구 전처리 — 분석코드의 입력 CSV를 만든다 |
| `code/data/population/`, `card/`, `cache/` | 공개 출처 데이터 |

읽는 순서는 `population.ipynb` → **`분석코드.ipynb`** → `03_심층분석.ipynb` → `부록_지표검증.ipynb` 입니다.
분석의 결론은 **`분석코드.ipynb` 하나로 전부 재현**되고, 나머지 셋은 각각 입력 생성·심층 분석·진단을 맡습니다.
